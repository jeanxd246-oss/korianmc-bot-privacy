1. Alcance de esta política

Esta Política de Privacidad se aplica a KORIANMC BOT (en adelante, «el Bot»), una aplicación de terceros para Discord. Describe las categorías de información que el Bot puede procesar para ofrecer las funciones activadas por los administradores del servidor.

Nota: esta política debe revisarse para que refleje con exactitud el código, las bases de datos, los registros y las funciones reales del Bot. No afirmes que el Bot elimina, cifra o nunca almacena datos a menos que eso sea cierto y verificable.

2. Información que puede procesarse

Según los comandos y módulos que estén habilitados, el Bot puede procesar:

  • Identificadores de Discord: ID de usuario, servidor, canal, mensaje o rol cuando sean necesarios para ejecutar una función.
  • Configuración del servidor: canales de registros, roles, categorías, opciones de moderación y otras preferencias configuradas por los administradores.
  • Contenido enviado al Bot: texto de comandos, formularios, reportes, sugerencias o tickets que los usuarios decidan enviar a través de funciones habilitadas.
  • Registros técnicos: errores y datos de diagnóstico que puedan ser necesarios para mantener el servicio, detectar abusos o solucionar problemas.

El Bot no necesita que envíes contraseñas, tokens de autenticación, datos bancarios ni información personal sensible. No los compartas en comandos, tickets o mensajes al equipo.

3. Finalidad, almacenamiento y divulgación

Cómo se utiliza la información

La información puede utilizarse para ejecutar comandos, conservar la configuración de un servidor, gestionar tickets y reportes, aplicar funciones de moderación, mantener la seguridad, diagnosticar errores y prevenir el uso abusivo.

Conservación y eliminación

La información se conserva durante el tiempo necesario para la función correspondiente o para fines operativos legítimos. El tiempo exacto depende de la implementación y configuración del Bot. Puedes solicitar que se revise o elimine información relacionada contigo, sujeto a obligaciones legales, de seguridad y a las limitaciones técnicas aplicables.

Proveedores y divulgación

La información puede pasar por servicios de alojamiento u otros proveedores técnicos utilizados para ejecutar el Bot. No vendemos deliberadamente información personal. La información también puede divulgarse cuando la ley lo exija o cuando sea razonablemente necesario para proteger la seguridad, los derechos de los usuarios o el servicio.

Seguridad

Se toman medidas razonables para proteger la información procesada. Sin embargo, ningún sistema digital puede garantizar seguridad absoluta.

4. Tus opciones y derechos

Puedes dejar de utilizar el Bot y pedir a los administradores que lo retiren de un servidor. También puedes contactar al equipo para preguntar qué información relacionada contigo se procesa o solicitar acceso, corrección o eliminación cuando corresponda.

Las solicitudes deben incluir información suficiente para identificar el contexto de la solicitud, pero no envíes contraseñas, tokens ni documentos sensibles por Discord. Es posible que cierta información deba conservarse por motivos legales, de seguridad o para resolver disputas.

Menores de edad

Utiliza Discord y el Bot únicamente si cumples los requisitos de edad aplicables en tu región. Evita compartir información personal sensible mediante el Bot.

Servicios de terceros

El uso de Discord está sujeto a sus propias políticas. Consulta la Política de Privacidad de Discord para conocer cómo Discord procesa la información.

Actualizaciones

Esta política puede actualizarse si cambian las funciones del Bot, sus prácticas de datos o los requisitos aplicables. La versión vigente se publicará en esta página y mostrará su fecha de actualización.
